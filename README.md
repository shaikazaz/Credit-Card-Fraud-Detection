\# Credit Card Fraud Detection



A machine learning project for detecting fraudulent credit card transactions using Python and LightGBM.



\## Project Overview



Credit card fraud detection is a binary classification problem where transactions are classified as either legitimate or fraudulent.



This project includes data preprocessing, handling class imbalance using SMOTE, model training with LightGBM, and evaluation using classification metrics.



\## Technologies Used



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- SMOTE

\- LightGBM

\- Matplotlib

\- Seaborn



\## Machine Learning Workflow



1\. Load the credit card transaction dataset

2\. Explore and preprocess the data

3\. Split the dataset into training and testing sets

4\. Handle class imbalance using SMOTE

5\. Train a LightGBM classification model

6\. Generate predictions

7\. Evaluate the model using:

&#x20;  - Precision

&#x20;  - Recall

&#x20;  - F1-score

&#x20;  - Confusion Matrix
